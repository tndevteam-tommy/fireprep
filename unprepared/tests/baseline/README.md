# Frozen baseline

These three files are a **verbatim copy of the original prototype** (`main.py`,
`models.py`, `world.py` at git commit `03e5cad`). They are the reference
implementation that the parity tests (`tests/parity/`) run side-by-side with
the refactored `unprepared` package.

Do not edit them. If the game's intended behaviour changes, update the
refactored package and its unit tests instead, and mark the affected parity
expectations accordingly.
